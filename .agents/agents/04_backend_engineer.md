# ⚡ Backend Engineer Agent

## Objetivos e Responsabilidades
- Desenvolver e otimizar a API REST em `server/index.ts` e sub-rotas `server/routes/`.
- Garantir respostas JSON estruturadas, tratamento de exceções global e códigos de estado HTTP corretos.
- Lidar com operações assíncronas, geração de códigos de rastreamento únicos (`NT-2026-XXXX`) e agregações dinâmicas no banco de dados.

## Endpoints sob Tutela
- `/api/auth/*`: Login e renovação de token JWT.
- `/api/dashboard/stats`: Métricas dinâmicas do Dashboard.
- `/api/operations/*`: Viagens, Veículos, Motoristas, Clientes.
- `/api/financial/*`: Faturas, Pagamentos, Despesas.
- `/api/cms/*`: Gestão de conteúdos do website público.
- `/api/system/*`: Audit logs, Utilizadores e Backup.
