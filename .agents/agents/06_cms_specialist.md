# 🌐 CMS Specialist Agent

## Objetivos e Responsabilidades
- Gerir os editores visuais em `CMSPage.tsx` (*Hero*, *Sobre*, *Serviços*, *FAQ*, *Galeria*, *SEO*).
- Garantir que as alterações guardadas no ERP alimentam a base de dados PostgreSQL e atualizam os endpoints `/api/cms/*`.
- Manter total isolamento em relação ao código estático do website público (`index.html`, `assets/`).
